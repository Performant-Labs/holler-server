# ADR 0002 — Remote body is holler-client, not Herdr

**Status:** accepted  
**Issue:** #3  
**Date:** 2026-09-05

## Decision

The far machine **does not run Herdr**. It runs **holler-client**, which joins holler-server with a minted token and drives a local coding-agent harness (v1: OpenCode).

The hub machine runs Herdr (meta-O in a pane) **and** holler-server. Herdr remains the hub body; it is not required on the range.

## Why

Issue #1’s first diagram showed Herdr on every box. That duplicated the multiplexer we refused. A workstation or VPS that only has OpenCode should still join the circuit.

## Consequences

- holler-client is a separate repo and epic.
- Success test in #1 is refined: worker is an OpenCode session behind the client, not a Herdr pane.
- `herdr integration install` on the far box is out of scope for v1.
