# ADR 0004 — WebSocket transport; Tailscale is not the app protocol

**Status:** accepted  
**Issue:** #5  
**Date:** 2026-09-05  
**Updated:** 2026-09-05 (IPv4 and IPv6; default stays 127.0.0.1)

## Decision

The circuit’s application protocol is **Holler v1**: JSON messages over WebSocket (`ws`/`wss`) between holler-client and holler-server. Canonical spec: [`docs/protocol/v1.md`](../protocol/v1.md) ([ADR 0009](ADR-0009.md)). Confidentiality of those frames is **TLS 1.3 on `wss`** ([ADR 0010](ADR-0010.md)). Plain `ws` is loopback only (`127.0.0.1` or `::1`).

**Listen is user-settable.** Default **`127.0.0.1:41807`** (IPv4 loopback; port IANA-unassigned). Flag `--listen [host:]port` (repeatable), env `HOLLER_LISTEN` (flag wins). Non-loopback binds require `wss`. If the client URL omits a port, it is 41807.

### IPv6

IPv6 is first-class. It is **not** the default (so boxes with IPv6 off still work, and `localhost` → `::1` does not surprise Windows).

| Want | `--listen` | Join URL |
| --- | --- | --- |
| Default / tests | `127.0.0.1:41807` | `ws://127.0.0.1:41807` |
| IPv6 loopback | `[::1]:41807` | `ws://[::1]:41807` |
| All IPv6 | `[::]:41807` | `wss://[2001:db8::1]:41807` |
| IPv4 + IPv6 | two `--listen`s | matching family |

Rules:

- IPv6 literals in URLs **must** be in brackets (RFC 3986).
- Do **not** default to the name `localhost` (often `::1` on Windows while we bound IPv4).
- One `--listen` is one socket / one address family. Do not assume `::` also accepts IPv4 (`IPV6_V6ONLY` differs by OS). To serve both, pass `--listen` twice.
- `holler status` reports every bound address.
- Client dials the URL as written (literal) or `getaddrinfo` for names (Happy Eyeballs is fine).
- Wire harness **requires** IPv4 `127.0.0.1`. An IPv6 `::1` case is extra and **skips** if `::1` is missing.

holler-client does **not** listen for Holler. It dials the server. ACP is stdio (no TCP port). OpenCode’s HTTP interrupt fallback uses *OpenCode’s* port (often 4096) — that is not Holler’s.

Any underlay (LAN, SSH tunnel, Tailscale, public IP) may make the TCP path exist. It is **not** Holler auth, not Holler addressing, and **not** Holler encryption. The client still must `join` with a server-minted token.

## Why not SSH as the protocol

SSH reaches a host. It does not name sessions, carry interrupt as a typed control frame, keep a roster, or let the worker holler back when nobody has a TTY. That is issue #1.

## Consequences

- Server binds `--listen` (default `127.0.0.1:41807`; IPv6 via `[::1]` / `[::]`; repeatable). Loopback `ws` allowed; non-loopback is `wss`.
- Reconnect uses the **client credential**, never a fresh join token, unless detached/revoked.
- No `ProxyCommand ssh` in the happy path.
