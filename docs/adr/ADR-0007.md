# ADR 0007 — Address sessions, not hosts

**Status:** accepted  
**Issue:** #8  
**Date:** 2026-09-05

## Decision

The unit of addressing is a **session name** on the circuit (`alpha`, `reviewer`), unique on that holler-server.

One holler-client process **may host many sessions** (the v1 gate: two OpenCode sessions on one remote). A host name is metadata on the roster, not the key for `holler-server say`.

## Consequences

- `holler-server say alpha …` not `holler-server say kiwi:4096`.
- Client registry maps session name → local OpenCode ACP session.
- Two remotes later is another client_id, still session names on the same circuit (collision policy: fail mint/advertise if the name is taken — pin in implementation).
