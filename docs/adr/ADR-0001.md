# ADR 0001 — Talk circuit, not a multiplexer

**Status:** accepted  
**Issue:** #2  
**Date:** 2026-09-05

## Decision

Holler is a **talk circuit**: a named, bidirectional message plane between a home (holler-server, next to Herdr) and remote **bodies** (holler-client + a coding-agent harness). It is not a terminal multiplexer, not a Herdr fork, and not `herdr --remote`.

## Closest prior art

Claude Desktop (MCP + Cowork Dispatch) is the analogy people reach for: “any agent talks to any other.” That is **not** what Desktop ships. MCP is agent→tools. Dispatch is phone→the same Claude on the desktop. Several open projects then bolted a **bus** on top of MCP or ACP. Holler sits in that family but is aimed at a different cut.

| Project | What it is | Why Holler is different |
| --- | --- | --- |
| **Heterogeneous agent frameworks** | Most buses assume one connector (MCP on every agent, or ACP on every agent, or “everyone is Claude”). | **This is the first requirement.** v1 body is OpenCode; Claude Code and others are on the roster unchecked. The circuit must not assume one harness, one protocol, or one vendor. A new body is an adapter, not a new plane. |
| [Herdr](https://herdr.dev) | PTY runtime + local Unix socket. Agents on **one box** can `herdr pane` / `herdr agent prompt` each other. Multi-remote ([#515](https://github.com/herdrdev/herdr/discussions/515)) is one TUI over many Herdr servers — still no shared bus. | Herdr is the **body on the hub**, not the circuit. A worker on a machine **without Herdr** cannot speak Herdr’s socket. Holler is the wire; Herdr stays optional on the far side. |
| [Buzz](https://github.com/block/buzz) | Relay as home; ACP harness as body; presence and `!shutdown` are relay messages. | Same *layer*. We take the tether/presence/message-control ideas, not Nostr, nsec-as-soul, or their code. |
| Claude Desktop / Cowork Dispatch | MCP tools; Dispatch runs **the same Claude** from phone onto a waking desktop. | Same-vendor, same-agent, desktop must stay open. Not a multi-harness remote circuit. |
| Google A2A | Cross-org agent cards and delegation. | Enterprise discovery, not “OpenCode on a homelab box joins with a token.” |
| [agent-mesh](https://github.com/mubashir1osmani/agent-mesh), [agent-bus](https://github.com/MustaphaSteph/agent-bus), [agent-comms](https://github.com/ExaDev/agent-comms), [CCCOG-MCP](https://github.com/WarmBed/CCCOG-MCP) | Local MCP/TCP/SQLite buses so Claude/Codex/OpenCode on **one machine** see each other. | Localhost (or one host). No server-minted join token, no first-class remote interrupt, no home that outlives the laptop. |
| [a2a-bridge](https://github.com/firstintent/a2a-bridge), [acp-bridge](https://github.com/xiwan/acp-bridge) | Translate ACP/A2A and expose local CLIs over HTTP. | Gateway/mesh for calling agents, not a token-joined session roster with cooperative interrupt for a meta-O. |
| herdr-mirror / herdlord / herdr-mx | See or attach to remote **Herdr** panes. | PTY attach/view. Workers cannot holler back. Far box must run Herdr. |

## Consequences

- Stories implement messages, tokens, roster, interrupt — not pane streaming.
- Do not merge Herdr sockets across machines.
- New harnesses (Claude, Codex, …) are client adapters, tracked unchecked on #1 until an epic lands them.
