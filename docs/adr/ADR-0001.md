# ADR 0001 — Talk circuit, not a multiplexer

**Status:** accepted  
**Issue:** #2  
**Date:** 2026-09-05  
**Updated:** 2026-09-05 (survey of existing tools, including X)

## Decision

Holler is a **talk circuit**: a named, bidirectional message plane between a home (holler-server, next to Herdr) and remote **bodies** (holler-client + a coding-agent harness). It is not a terminal multiplexer, not a Herdr fork, and not `herdr --remote`.

Nobody has shipped this exact cut. Several projects overlap a piece of it. We steal **ideas**, not code.

## Recommendations

1. **Do not vendor or fork [c2c](https://github.com/clankercode/c2c).** Closest product (heterogeneous CLIs + optional tokened relay), but the GitHub repo has **no `LICENSE` file** (`license: null`). The npm wrapper `@clanker-code/c2c` declares MIT; that does not clearly cover the OCaml broker. Treat it as source-available. Use it as a reference for join/send/status and per-harness *wake* pain, not as a dependency.
2. **Steal token UX from c2c’s relay (`--token`) and from [ai-crew-sync](https://github.com/joaquinbejar/ai-crew-sync)** (`token issue` / list / revoke). Holler’s operator surface is `holler token mint` / `list` / `delete` / `ping` (ADR 0003). Keep the two-step join: short-lived mint → redeemed client credential; list shows the **machine hostname** once bound.
3. **Do not become a mux.** Herdr, Orca, ttt, herdr-mirror, and “tmux as the bus” are attach/type-into-a-PTY. That is the thing #1 rejected.
4. **Do not assume MCP-on-everyone.** First requirement is **heterogeneous frameworks**. v1 body is OpenCode via ACP; Claude and others stay unchecked on #1.
5. **Interrupt stays a control frame** (ADR 0005), not “another inbox message the model might poll.” c2c’s own docs: Claude/Grok often **cannot wake from idle**; hooks are not a cancel. Holler maps interrupt to ACP `session/cancel` / OpenCode HTTP interrupt.
6. **Keep the far box Herdr-free.** Claude Code’s own [cross-session messaging](https://code.claude.com/docs/en/cross-session-messaging) and Harness Remote still assume their harness (or Anthropic Remote Control) on the target. Holler-client *is* the body.
7. **Protocol is Holler v1** ([`docs/protocol/v1.md`](../protocol/v1.md), ADR 0009). `query` / `support` are commands with arguments, not a prompt to a model. The server answers the same status document as a client.

## Closest prior art (researched 2026-09-05)

Claude Desktop (MCP + Cowork Dispatch) is the analogy people reach for: “any agent talks to any other.” That is **not** what Desktop ships. MCP is agent→tools. Dispatch is phone→the same Claude on the desktop.

### Cross-machine / token-ish (the interesting pile)

| Project | What it is | vs Holler |
| --- | --- | --- |
| **Heterogeneous agent frameworks** | Most buses assume one connector (MCP on every agent, ACP on every agent, or “everyone is Claude”). | **First requirement.** OpenCode today; Claude and others unchecked on #1. A new harness is an adapter, not a new plane. |
| **[c2c](https://c2c.im/)** ([clankercode/c2c](https://github.com/clankercode/c2c)) | Heterogeneous CLIs (Claude, Codex, OpenCode, Grok, Pi, Kimi, agy, Hermes). Local file broker + optional HTTP/WS relay with `--token`. `c2c send` / `monitor` / `status`. **Alpha.** | Strongest product match. Cross-machine is inbox **sync/poll**, not a live WS circuit. Wake is uneven (OpenCode/Pi guaranteed; Claude/Grok often idle-deaf). **License: GitHub `null`; npm wrapper MIT — do not vendor.** |
| **[ai-crew-sync](https://github.com/joaquinbejar/ai-crew-sync)** | Postgres bus, `token issue` / revoke, presence, tasks, MCP HTTP. Cross-user and cross-machine. | Token identity is real. Still MCP-shaped; far box must be an MCP client. No ACP cancel as the product. |
| **[swarmcode](https://github.com/spranab/swarmcode)** | Redis channel so **Claude Code on different machines** can message. | Cross-machine yes. Claude-only. Shared Redis, not a minted join token. |
| **[Harness Remote](https://github.com/giuliastro/opencode-remote-android)** | Control plane over native OpenCode / Claude / Codex / Pi sessions across devices. | Remote **observe/resume/handoff**, not a talk circuit. You attach to *their* session. |
| **[opencode-orchestrator](https://github.com/autonomica-xyz/opencode-orchestrator)** | CLI against `opencode serve` HTTP on several hosts. | You configure URLs (SSH-shaped). No join token, no other harnesses. |
| **Claude Code [cross-session messaging](https://code.claude.com/docs/en/cross-session-messaging)** | `SendMessage` across machines via Anthropic Remote Control + per-session token. | Official, works. **Claude-only**; other-machine traffic through Anthropic. |
| **[Buzz](https://github.com/block/buzz)** | Relay as home; ACP body; presence and `!shutdown` are messages. | Same *layer*. Not a clone (no Nostr/nsec). Apache-2.0. |
| **[Herdr](https://herdr.dev)** | PTY runtime; local socket; multi-remote ([#515](https://github.com/herdrdev/herdr/discussions/515)) is one TUI over many Herdr servers. | Closest *sibling*. Hub body, not the bus. Far box need not run it. Apache-2.0. |

### Same machine (not the problem)

[agent-mesh](https://github.com/mubashir1osmani/agent-mesh), [agent-bus](https://github.com/MustaphaSteph/agent-bus), [agent-comms](https://github.com/ExaDev/agent-comms), [CCCOG-MCP](https://github.com/WarmBed/CCCOG-MCP), [agent-channel](https://github.com/fl4p/agent-channel), [agent-message](https://github.com/slima4/agent-message), OpenCode’s in-process cross-session plugin — files / SQLite / localhost TCP. One host.

[a2a-bridge](https://github.com/firstintent/a2a-bridge), [acp-bridge](https://github.com/xiwan/acp-bridge) — HTTP/A2A gateways in front of local CLIs. Call an agent; not a session roster with cooperative interrupt for meta-O.

herdr-mirror / herdlord / herdr-mx — attach or dashboard remote **Herdr** panes. PTY view. Workers cannot holler back.

Google A2A — cross-org agent cards, not “OpenCode on a homelab joins with a token.”

## Gap that remains (why Holler still exists)

A **small server that mints a join token**, a **client on a box with no Herdr**, **OpenCode (then Claude) as adapters**, **interrupt as ACP cancel with the session still alive**, and **meta-O talking over CLI without SSH**.

c2c is the tool to read. ai-crew-sync is the token cousin. Claude’s own messaging proves cross-machine *for Claude*. Buzz is the architecture. Herdr is the hub body. None of them is Holler.

## Consequences

- Stories implement messages, tokens, roster, interrupt — not pane streaming.
- Do not merge Herdr sockets across machines.
- New harnesses (Claude, Codex, …) are client adapters, tracked unchecked on #1 until an epic lands them.
- Do not add c2c as a dependency until they ship a repo-root LICENSE we can live with.
