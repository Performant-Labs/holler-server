# ADR 0006 — Presence is status

**Status:** accepted  
**Issue:** #7  
**Date:** 2026-09-05

## Decision

The roster is **conversational availability**, not “is sshd up” and not “did we attach a TUI.”

holler-client heartbeats. Each advertised session has a TTL. When heartbeats stop, the server marks the client/session stale and drops it from `holler roster` after TTL (bounded wrong dot, never an indefinite one — Buzz I3, not their code).

`holler status` is **circuit health** (listening, connected, credential present). `holler roster` is **who can be hollered at**.

## Consequences

- Do not scrape remote process tables over SSH for the roster.
- A client can be connected with zero sessions (show in status, empty roster).
- Gate requires both sessions visible on roster before `say`.
